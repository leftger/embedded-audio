Function mel_filterbank_f32 

pub fn mel_filterbank_f32(
    power_spectrum: &[f32],
    fft_size: usize,
    sample_rate_hz: f32,
    low_freq_hz: f32,
    high_freq_hz: f32,
    mel_energies: &mut [f32],
) -> Status
Expand description

Applies a triangular Mel filterbank to a one-sided power (or magnitude-squared) spectrum, producing one energy value per Mel band — the standard first step of MFCC / speech feature extraction.

power_spectrum: one-sided spectrum of length fft_size / 2 + 1 (DC through Nyquist). fft_size: the FFT length the spectrum was computed with. sample_rate_hz: sampling rate in Hz. low_freq_hz / high_freq_hz: frequency range to cover with Mel bands (0..=sample_rate/2). mel_energies: destination for the output; its length sets the number of Mel filters M (1..=64).
